# Superb

面向 Windows 11 x64 的受控 Agent 转发客户端。使用原生 WPF 阅读面板、Win32 采集与剪贴板接口，以及可配置的 Chat Completions 后端。

**当前为 0.2.0 开发版本，尚未完成 Windows 桌面采集保护验收，不能作为已验证的保密产品发布。** 已实现采集 → 本地处理 → 受控发送 → 流式阅读 → 可选剪贴板输出的代码闭环。采集排除、焦点行为、多屏 DPI、锁屏和系统剪贴板兼容性需要实测；没有任何采集软件组合被标记为已通过。

## 运行与构建

开发环境需要 .NET 10 SDK。Windows 用户可以运行：

```powershell
dotnet run --project src/Superb.Desktop
```

生成自带运行时的 Windows x64 文件夹：

```powershell
dotnet publish src/Superb.Desktop -c Release -r win-x64 --self-contained true -o artifacts/win-x64
```

运行生成目录中的 `Superb.exe`，保留同目录依赖。无需管理员权限。首发开发基线为 Windows 11 x64（构建 22000+）；这只是启动约束，正式支持范围以验收矩阵为准。没有配置供应商、API 密钥或有效后端时不会发送网络请求。仅允许一个本机会话实例。

## 首次使用

1. 首次打开进入“模型”页，展开“快速连接 DeepSeek”。填入 DeepSeek 密钥，点击“测试并保存”；无需填写接口和模型。默认直连，代理放在折叠的“高级连接设置”中，按需选择。
2. 应用从 DeepSeek 官方 `/models` 获取可用模型，优先选择 `deepseek-flash`，其次 `deepseek-chat`，否则选择列表首个模型；用固定文本做一次最多 64 tokens 的测试。只有完整文本响应通过后，才加密保存密钥并进入浮窗。新的快速配置预设为 200000 生成 tokens、300 秒超时，思考模式沿用模型默认；新建通用连接也默认 200000 tokens，默认响应字符上限为 1000000。已有后端不会自动提高限额。失败或取消不覆盖旧配置、不自动重试或更换线路。图像能力仅在服务端模型元数据明确声明时启用。
3. 连接成功后进入置顶的悬浮工作区；已有后端时，启动直接进入浮窗。点击输入框会进入交互模式并使原窗口失焦，无需先点“编辑”；也可按 Ctrl+Alt+E 启用编辑后再点击输入框。鼠标选择场景保持阅读模式，不取得键盘焦点。“读剪贴板”“两点截图”“截当前屏”统一追加到待发送队列，可连续收集、逐项移除或清空，再补充要求并点击“发送”（编辑时可按 Ctrl+Enter）。场景选择不会自行读取剪贴板；每次提问独立，不自动附带历史。
4. “两点截图”依次点击同一显示器内的两个对角，先后顺序不限；右键、Esc 或 60 秒超时取消，现有队列保留。选点点击不会传给底层页面。“截当前屏”采集鼠标所在显示器；采集时隐藏 Superb 窗口，无需预设范围。队列最多 10 项，其中最多 5 张图片，累计正文与图像原始大小最多 16 MiB、累计图片最多 3200 万像素；超限提示且不删除已有项。发送仍需满足后端更严格的限额与图像能力要求。已出回答后再次收集输入会开启下一任务，替换旧队列并清除旧问题和回答。
5. 设置分为“模型、场景、快捷键、通用与自动化”。模型页编辑连接、思考模式、生成 tokens 和超时；新建与删除模型配置直接位于连接选择框下方。删除会清除引用它的固定路由，保留其他默认选择和共享凭据；仍被场景指定的模型需先调整场景。端点密钥、代理和兼容参数折叠显示。场景页编辑提示词，快捷键页配置全部绑定；“通用与自动化”默认展开剪贴板偏好，另有自动同步、预设截图、模型路由、JSON 预处理及保护状态。路由通过模型名称下拉选择，图像路由要求支持图像；默认跟随模型页的默认连接。模型、场景、快捷键的保存入口固定在页底；快捷键、剪贴板偏好、模型路由和预处理分别保存，不互相提交未保存的修改。既有固定路由保持不变，浮窗显示实际接收方。
6. “停止生成”保留已生成的部分回答，明确标为未完成，可手动复制，不自动写回。“重新回答”沿用上次冻结的输入、场景和模型；“新任务”取消旧任务并清空当前输入和回答。“暂停”、锁屏和退出仍清除敏感内容。自动写回需独立启用，且只用于完整回答；剪贴板在请求期间变化时跳过自动写回。

浮窗默认阅读模式，显示和更新不主动激活；“编辑”明确进入可输入、可选择文字的交互模式，Esc 或“完成编辑”返回阅读。点击“穿透阅读”后鼠标交给底层应用，用 Ctrl+Alt+E 返回编辑；该键及设置、暂停、退出入口未注册成功时，不允许进入穿透。浮窗不进入任务栏，显隐保持置顶及尺寸；窗口位置、大小和字号继续保存。“设置”打开配置窗口并保留上次所选页，“返回悬浮工作区”回到浮窗。连接成功时，若设置仍在前台则保留设置，等待用户主动收起。配置窗口不再重复显示问题与回答；浮窗使用本地文本／代码渲染，流式更新保留已有段落；向上阅读后暂停跟随，点击“回到最新”恢复。

生成开始后，“输入与队列”自动折叠，为回答保留主要空间；可以手动展开，流式更新不会再次折叠用户展开的输入。新收集的输入会重新展开队列。“外观”可直接调节宽、高、背景不透明度（25%–100%）和回答字号（11–36）；文字始终实色，字号只影响回答。右下角绿色三角可拖动缩放，“舒适阅读”放大并专注回答，“恢复默认”恢复 600×740、18 号字和不透明背景。窗口尺寸按当前显示器工作区收敛，位置、尺寸、字号和背景比例在停止调整 500ms 后保存；旧配置默认背景不透明。穿透模式下先用 Ctrl+Alt+E 退出穿透，再拖动或调节。普通阅读模式即可操作外观，无需进入编辑。正在输入时打开或关闭外观会保留输入区、焦点及选区；小窗口优先保留输入空间，外观区可滚动。

输入框上方直接提示“点击输入会使原窗口失焦”；外观面板内直接提示“调整外观可能使原窗口失焦”。操作后需要继续原应用时，请手动点击原窗口；这些说明直接显示，不弹出确认框。外观按钮、滑块及预设按钮的悬停说明采用相同提示。

浮窗按钮下方显示当前已注册的快捷键，保存自定义绑定后同步更新；停用、独占接管未开、未注册和注册失败分别标示。没有专用键的操作标为“仅鼠标”，鼠标悬停提示文字可查看完整绑定及状态。局部截图选择中显示 Esc／右键取消，暂停后的恢复显示恢复键；复制部分回答和直接回答重试不会误标普通完整复制／重答键。队列单项移除只有最后一项显示“移除最后一项”的绑定，其余项仍为鼠标操作。提示不新增或修改任何键位。

DeepSeek 官方接口依据：[首次调用](https://api-docs.deepseek.com/zh-cn/)、[模型列表](https://api-docs.deepseek.com/api/list-models/)。快速配置只向 `api.deepseek.com` 发出模型查询和固定文本测试，不读取剪贴板或截图，不显示或保存测试回答。已有 DeepSeek 可直接使用；重新快速配置需填入密钥。需要保留自定义生成参数时使用高级编辑器。

Live Clipboard 需在每次会话中明确授权输入格式、接收后端、期限及是否允许自动发送。期限默认 10 分钟，上限 60 分钟。400 ms 去抖、至少 2 秒采集间隔、内容哈希去重、过滤本应用输出；繁忙时合并为最新一次剪贴板变更。启动授权时不自动读取已有剪贴板。停止 Live Clipboard 会撤销后续自动输入并丢弃尚未发送的自动准备任务，但不会把已经提交的请求伪装成“可撤回”；现有请求可独立取消，紧急暂停仍会遮蔽敏感显示并停止本地输出。

默认全局快捷键：

| 快捷键 | 动作 |
| --- | --- |
| Ctrl+Alt+1 / 2 | 读剪贴板加入队列 / 两点截图加入队列 |
| Ctrl+Alt+D | 鼠标所在屏幕加入队列 |
| Ctrl+Alt+Backspace | 移除队列最后一项 |
| Ctrl+Alt+3 / 4 | 显示或收起阅读面板 / 复制完整回答 |
| Ctrl+Alt+5 / 6 | 取消当前任务 / 紧急暂停 |
| Ctrl+Alt+7 | 发送整个工作区队列及补充要求 |

快捷键冲突会列出注册失败的动作。程序不主动切换焦点：启动、打开或恢复设置、显示浮窗、切换编辑／阅读、发送和后台更新都不主动激活窗口，也不自动跳回之前的应用。编辑快捷键仅启用交互，输入时请点击输入框；Esc／完成编辑只结束编辑，保留当前窗口焦点。用户点击、隐藏或关闭当前活动窗口时，焦点由 Windows 的正常行为决定。阅读面板不进入任务栏，可以拖动标题栏、从右下角调整大小；位置、大小、字号和显隐状态会保存。

文字输入、选字、点击设置、隐藏活动窗口、截图隐藏及系统保存对话框的失焦影响均有界面提示。普通按钮、场景鼠标选择、滑块、缩放与标题拖动已移除不必要的编辑／激活路径；本轮已完成 Windows 原生鼠标回归及 Chrome／Edge 共 60 轮事件对照；修复回答拖选、回答区无功能右键抢焦点及草稿滚动误进编辑。排查清单和验证边界见 [焦点交互排查](docs/focus-interactions.md)。

## 预处理与固定路由

处理规则按数组顺序执行，裁剪、遮盖的坐标相对上一步图像。以下示例仅用于图像：

```json
[
  { "Kind": "Crop", "Required": true, "Rectangle": { "X": 0, "Y": 0, "Width": 800, "Height": 600 } },
  { "Kind": "Mask", "Required": true, "Rectangle": { "X": 20, "Y": 20, "Width": 180, "Height": 40 } },
  { "Kind": "Resize", "Required": true, "MaxDimension": 1600 },
  { "Kind": "Template", "Required": true, "Template": "请解释图片内容。{input}" }
]
```

文本可使用 `NormalizeText` 和 `Template`。不处理正文时使用空数组 `[]`。仅 `Required: false` 且 `SkipOnFailure: true` 允许失败后跳过；界面显示跳过计数。队列中的每张图片分别执行同一套裁剪、遮罩、缩放；任意一张的强制步骤失败，整批不发送。新图像逐像素重新编码，遮盖区域为实色像素，不附加原图或元数据。

固定路由只依据处理产物是否带图像，使用配置中列出的后端 ID：

```json
{ "TextBackendId": null, "ImageBackendId": null }
```

`null` 使用手动选择。自动同步固定绑定获授权的一个后端；路由指向另一个后端时拒绝发送。用户文本、截图内文字和模型回答不会成为策略指令。

## 存储和边界

- 配置保存在 `%LOCALAPPDATA%\Superb\settings.json`，凭据单独保存在 `credentials\*.dpapi`，采用当前用户 DPAPI。配置导出去掉凭据引用及采集目标。规则模板属于持久配置，不要把敏感正文写进模板。
- 截图、剪贴板正文、回答和请求历史默认只在内存；无应用内容日志、自动遥测、崩溃上传或临时图像文件。暂停/锁屏/退出清除显示和会话引用，默认只清除仍由本应用拥有的剪贴板输出。托管字符串、图形缓冲、系统分页与第三方转储无法保证绝对擦除。
- 所有后端流量经过同一个客户端，验证 HTTPS 证书，禁用重定向、Cookie 和自动重试。每个后端可选择直连、系统代理或自定义 HTTP/HTTPS/SOCKS5 代理；旧配置仍为直连。普通网络代理填写在“自定义代理地址”，不要替换模型端点。模型协议目前仅实现 Chat Completions；不支持工具调用、Responses、Anthropic 原生协议、OCR 或浏览器自动化。
- 每次请求独立，流必须包含合法 `finish_reason: stop` 及 `[DONE]` 才完成。截断、长度上限、限流及内容过滤结果不会自动写回。手动重试沿用冻结后的输入和后端，但创建新的尝试 ID，可能产生新的计费。
- 阅读器通过 Markdig 解析 Markdown，再生成原生 WPF 文本元素，支持标题、粗体／斜体／删除线、行内与围栏代码、嵌套列表、引用、分隔线和管道表格。带语言标签的围栏代码支持基础语法高亮：Python、C/C++、C#、Java、JavaScript、JSON、HTML/XML、CSS、SQL、PowerShell；TypeScript 沿用 JavaScript 基础规则。未标语言、未知语言或超长代码块显示纯文本。流式更新重新识别未闭合标记，保留未变化的块和阅读位置；整段复制与自动写回仍使用原始 Markdown。链接显示文字及地址，图片仅显示说明及地址；不解析 HTML/XAML、不自动加载远程资源、跳转链接或执行命令。系统剪贴板历史/云标记不阻止其他进程读取当前剪贴板。
- 当前采集原型采用 GDI `BitBlt` 和窗口 `PrintWindow`，不是 WGC。拒绝黑帧和变化的几何范围，不做全桌面回退。部分 GPU 窗口可能无法正确采集；需要用验收证据冻结支持范围。PrintWindow 超过 5 秒后停止消费结果，底层调用不能强制终止，最多保留一个在途采集线程。
- `WDA_EXCLUDEFROMCAPTURE` 设置成功只表示属性可检查，不能证明所有采集链路安全。运行中每 100 ms 及敏感渲染前检查；外部改变保护与检测之间存在时间窗口，必须逐帧验证。不存在进程隐藏、注入、关闭系统安全提示或对高权限攻击者的保证。

## 验证

连接问题先在“模型 → 编辑模型与连接”保存正确的连接方式，再点“测试已保存连接”。该动作使用同一请求实现和固定文本 `Reply with OK.`，不读取剪贴板、不显示或写回测试回答。界面会区分 DNS、TCP、TLS、代理、HTTP 状态和响应格式错误；模型不支持 `temperature` 或 `max_tokens` 时，可关闭前者并选择 `max_completion_tokens`。详细步骤见 [后端连接排查](docs/backend-connectivity.md)。

DeepSeek 官方端点可选择“沿用模型默认 / 直接回答 / 深度思考”。模型上下文与本次 `max_tokens` 不同；新建模型默认生成预算为 200000 tokens，包含思考与正文。DeepSeek 官方端点的本地校验上限为 393216，通用后端为 200000；服务端实际上限由所选模型决定，超出时需调低配置。长回答可调高超时，最多 600 秒。已有用户修改并保存后应点“发送”；普通“重新回答”始终沿用旧请求参数。思考期间只报告活动状态，不展示或保留推理正文。token 耗尽、内容过滤、服务中断和空回答分别报错。官方 DeepSeek 因 token 耗尽失败时，可明确选择浮窗的“直接回答”：仅该次关闭思考、将生成预算设为至少 16384，保留上次处理后的输入、模型、路由和保护规则，不修改保存的默认值、不自动重试。

跨平台核心测试（自包含控制台测试器，失败时非零退出）：

```powershell
dotnet build Superb.slnx -c Release
dotnet run --project tests/Superb.Tests -c Release
```

Windows 专用测试：

```powershell
dotnet run --project tests/Superb.WindowsTests -c Release
dotnet run --project tests/Superb.WindowsTests -c Release -- --interactive
# 仅在可覆盖当前剪贴板的测试会话运行：
dotnet run --project tests/Superb.WindowsTests -c Release -- --clipboard
```

普通 Windows 测试处理合成位图、一次性合成凭据、本机模拟后端、配置保存失败回滚及 WPF 页面离屏渲染。可追加 `--render-dir artifacts/ui` 导出三个页面的 PNG；这不等于交互式桌面操作验证。`--interactive` 检查窗口属性，不能替代采集排除实测；`--clipboard` 会覆盖当前剪贴板。CI 固定使用 Windows Server 2025，运行核心/真实代理传输/图像/DPAPI 到 HTTP 集成测试并打包，同时保留操作系统、SDK 和测试记录。其结论不等于 Windows 11 桌面行为已验收。

### 场景预设与可编辑快捷键

悬浮工作区提供 AI Coding 协作、算法题、通用问答及直接提问模式。界面选择场景只改变回答方式，输入来自可见草稿及当前队列。旧的一键场景快捷键仍保留：默认 Ctrl+Alt+C、Ctrl+Alt+A、Ctrl+Alt+G，按各场景配置的来源立即采集并发送（默认剪贴板），不合并工作区队列；场景来源为截图时仍使用“通用与自动化”中的预设范围。Ctrl+Alt+1 / 2 和界面上的读取／截图按钮都只追加队列，Ctrl+Alt+7 统一发送。每次只发送本次场景的 system 提示词和 user 消息，不携带历史或其他场景内容。

在“场景”页编辑名称、输入来源（剪贴板 / 浮窗输入框 / 预设截图范围）、系统提示词、含 `{input}` 的用户模板，以及独立后端、模型、温度与 token 覆盖。后端留空时遵循当前选择及固定路由；明确指定场景后端时优先使用它，失败不切换。场景模板在全局预处理之后应用，遮罩等必要步骤不会被绕过。后端禁用 temperature 时场景温度覆盖也不会使它重新发送。场景运行会停止正在进行的 Live Clipboard 授权，避免后台自动请求抢占本次手动请求。当前输入、回答及历史不写入场景配置；提示词与模板本身会保存。

“快捷键”页统一列出所有动作和场景的绑定，可逐项修改、启停、恢复默认：

- 普通组合键：例如 Ctrl+Alt+C。修饰键可能到达网页，不承诺零网页事件。
- 独占单键：F1–F11、F13–F24。必须开启“独占单键接管”才生效；其按下、重复与释放由 Superb 消费，其他应用失去该单键功能。模式切换会填入建议值，仍可编辑；建议值不代表无冲突。例如 F6 常用于切换焦点，F11 常用于全屏，F13–F24 可能需要专用硬件。F12、Windows 键组合及若干保留组合不允许配置。

接管总开关默认关闭，默认绑定为普通组合键。新建自定义场景的快捷键默认禁用。重复绑定在保存前拒绝；其他程序已注册的冲突会显示失败动作，网页自定义快捷键无法全面预判。请松开所有按键后保存或退出。完整主窗口收起前仍检查设置、暂停和退出入口可用。

配置升级到 schema 2：保留旧自定义组合键；旧“独占阅读键”开关开启时迁移为 F6/F7/F8 独占绑定并保留接管开启状态。新配置不再使用固定阅读键覆盖。新增默认键与旧键冲突时优先保留旧键并停用新增绑定；旧的普通单键或不再允许的组合会保留值但停用，需在编辑器确认后启用。旧配置只在显式保存时写回。
