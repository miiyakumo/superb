# Superb

当前版本：**1.1.0**。

Windows 11 x64 上的桌面客户端。它从剪贴板或屏幕采集内容，发给你配置的 Chat Completions 接口，在置顶浮窗里流式阅读回答，并可选写回剪贴板。

## 开始使用

下载 Windows x64 压缩包，解压后双击根目录的 `Superb.exe`。程序自带 .NET 运行时，说明和许可证在 `docs/` 中。[下载 v1.1.0](https://github.com/miiyakumo/superb/releases/download/v1.1.0/Superb-v1.1.0-windows-x64.zip) · [SHA-256 校验文件](https://github.com/miiyakumo/superb/releases/download/v1.1.0/Superb-v1.1.0-windows-x64.zip.sha256)

在仓库根目录运行：

```powershell
dotnet run --project src/Superb.Desktop
```

在 Windows 桌面会话中用 PowerShell 7 打包并验证自带运行时的 Windows x64 版本：

```powershell
pwsh -File tools/publish.ps1
```

本地启动入口固定为 `artifacts/current/win-x64/Superb.exe`。可分发的 ZIP 和 SHA-256 文件位于 `artifacts/current/`。解压 ZIP 后直接运行 `Superb.exe`，说明和许可证在 `docs/`。脚本用解压后的程序验证窗口资源、公式渲染和截图，成功后才替换当前版本。

### 连接模型

1. 打开「模型」，按接入方式选择模板并点击「新建模型配置」，也可直接填写空白表单。支持 OpenAI 官方、DeepSeek 官方、第三方兼容网关和本机服务，通信协议统一为 OpenAI Chat Completions；其他原生协议需通过兼容网关接入。
2. 填写配置名称、模型 ID、服务地址和服务要求的 API 密钥。URL 可填写域名、以 `/v1` 结尾的 Base URL 或完整 Chat Completions POST 地址；前两种会自动补全路径。自定义路径按完整接口地址使用。本机模板填入 `127.0.0.1:11434/v1/chat/completions`，请按实际服务修改地址和端口；无认证的本机服务可留空密钥。
3. 「测试当前配置」使用当前表单中的模型、地址、参数和未保存密钥，发送固定文本 `Reply with OK.`。新配置不用先保存；测试可能计费，不读取工作区输入或截图，不展示或保存测试回答，也不自动保存配置。成功后点击「保存模型配置」。首次连接自动成为默认；已有默认连接时，保存其他连接不会切换默认项，需在连接列表选中后点击「设为默认」。编辑已有连接时，密钥留空会保留已有凭据。
4. 新建配置默认 200000 生成 tokens、1000000 响应字符、300 秒超时；请按模型服务的实际上限调整。图像能力在高级选项中设置。已保存的后端限额保持不变。DeepSeek 官方端点的本地 tokens 上限为 393216，其他端点为 200000；服务可能要求更低的值。配置或凭据保存失败时保留旧配置。
5. 已有可用后端时，下次启动直接进入浮窗。设置窗口的 × 和页签右侧「返回工作区」只隐藏设置，保留浮窗及当前任务；旁边按状态显示「暂停」或「恢复」。设置顶部仅在配置、快捷键、会话或任务异常时显示状态卡片，普通进度在工作区查看。通过浮窗「设置」可重新打开。结束整个程序需点击「退出 Superb」或使用退出快捷键。

模型连接统一保存端点、密钥、模型和生成参数。场景保留名称、系统提示词和可选的模型连接；未指定时使用当前默认连接。文字与图片使用同一选择规则，包含图片而当前连接不支持图像时，会提示更换连接。需要另一组模型或生成参数时，新建模型配置并让场景选择它。

场景快捷键保留；编程问答会续接当前任务，其他场景按本次输入回答。输入和截图都来自当前工作区队列，准备好后手动发送。用户消息直接附加输入，不再配置 `{input}` 模板或场景截图来源。代理、本机 HTTP、图像能力、温度及其发送开关、token 参数名称和流式兼容选项集中在折叠的「高级选项」里。URL、密钥、tokens 和超时直接展示，详细说明放在悬停提示中；思考模式开关仅在 DeepSeek 官方接口下展示；输入字节数与响应字符数限额保留在内部，编辑连接时原样保留已有值。

旧设置升级到 schema 6 前，会在设置文件旁保存 `.upgrade-*.bak` 原文备份。旧场景的模型与生成参数覆盖迁成独立模型配置并绑定该场景；自定义用户模板中的任务说明移入系统提示词。原有连接、凭据引用、技术限额和场景快捷键保留，固定文字／图片路由不再参与选择。 原先受总开关抑制的独占键迁成逐项停用，原本有效的绑定保持启用；迁移后只按每行的状态与模式注册。

连接失败时的区分和代理写法见 [后端连接排查](docs/backend-connectivity.md)。

## 用「编程问答」接续平台 AI 的工作

1. **首次同步。** 选择「编程问答」，把需求、相关源码和当前卡点一起发给 Superb。例如，要求求和函数保留负数，但测试 `total([-2, 1])` 得到了 `1`。
2. **带回改动。** 平台 AI 修改后，直接发送它的分析和 diff。Superb 会结合上一轮建议判断改动是否处理了失败原因。需要继续改代码时，把短指令转述给平台 AI，并用 `@文件` 关联对应源码。
3. **继续验证。** 下一轮可以只贴最新测试输出。Superb 会接着前两轮分析；点击「重答」可重做当前一轮。开始另一项工作时点击「新任务」。

会话保存在内存中，暂停、锁屏或退出会清空历史。在模型连接高级设置中可填写上下文窗口，留空按 32,768 tokens 估算。达到可用输入预算的 80% 时，Superb 会整理较早的完整问答，目标是降至 60%。本轮新材料始终原样发送。系统提示词和历史压缩提示词都可以在场景设置中修改。

## 悬浮工作区

回答支持 Markdown 标题、列表、引用、表格和代码高亮，以及离线数学公式渲染。行内公式使用 `$…$` 或 `\(...\)`，独立公式使用 `$$…$$` 或 `\[…\]`，独立公式也可跨行书写。支持常见分式、根式、上下标、求和与积分等数学表达式；不支持的 LaTeX 命令、未闭合或过于复杂的公式会显示源码。代码中的公式标记保持原样，复制回答也保留原始 Markdown / LaTeX。

正文采用更宽松的行距与分级标题留白，普通 Markdown 换行按段落自动折行；需要强制换行时使用行末两个空格。公式随回答字号与主题更新，超宽公式缩小到可用宽度。数学渲染组件及字体许可随应用保存在 `ThirdPartyNotices` 目录。

浮窗固定为只读工作区，不提供手输输入框或编辑模式。问题和补充要求从剪贴板加入材料队列，也可使用截图。空白、边框和答案文字上的点击、拖动、滚轮交给下层应用；按钮、场景选择、滚动条、标题拖动区和缩放角仍可操作。使用滚动条或翻页快捷键阅读，点击复制按钮获取回答。显示、拖动和缩放不会主动激活浮窗；右下角缩放保持普通箭头。「全穿透」让按钮等区域也穿透，默认 Ctrl+Alt+E 切换全穿透／恢复操作。穿透、设置、暂停、退出快捷键未注册成功时，不允许进入全穿透。旧编辑快捷键迁移为穿透切换，保留自定义按键及启用状态。

「读剪贴板」「两点截图」「截当前屏」只入队，不会自己把剪贴板发出去。两点截图在同一显示器上点两个对角，顺序不限；右键、Esc 或 60 秒超时取消，已有队列保留。「截当前屏」取鼠标所在显示器，采集时隐藏 Superb。队列最多 10 项，其中最多 5 张图片。正文与 PNG 字节合计不超过 16 MiB。每张图片不超过 3200 万像素，全部图片加在一起也不超过这个数。超出时提示，不删除已有项。

点击「发送」或使用发送快捷键发送队列。发送后「材料队列」收起，给回答留出空间；手动展开后，后续流式更新不会再把它折叠。回答完成后再次采集会换掉旧队列。在编程问答中，新输入作为当前任务的下一轮发送。

频繁整屏提问可以点击「发送」旁边的「截屏并发送」，或按默认独占单键 **F4**：截取鼠标所在显示器，使用触发时的场景和模型，**以本次截图作为本轮输入**，不带上已有队列文字。截图成功并通过校验后才替换旧队列、问题和回答；截图失败、输入超限或模型不支持图片时保留原内容。取消会阻止迟到截图发送；暂停仍按原规则清空敏感内容。生成期间不会插入新请求，请先停止；「重答」重发已冻结的输入，不重新截图。原有 Ctrl+Alt+D 仍只截图入队。所有快捷键逐行启用，右键按键输入框或按 Shift+F10 配置该行动作的独占模式，不再设置总开关；F4 与其他动作使用同一规则。完整消费无修饰键的按下、长按重复和释放，长按只触发一次。Alt+F4 等带修饰键的组合不由此动作接管。旧版未自定义的 Ctrl+Alt+X 升级为 F4，禁用状态和其他自定义绑定保留；若与已有绑定冲突，保留旧绑定并停用新键。系统注册失败会标记未生效，不降级成会透传的普通按键。浏览器事件是否完全被拦截应以实际平台测试为准，不承诺对所有监听机制不可检测。

「停止生成」留下已生成的部分和当前队列，标成未完成，可以手动复制，不自动写回。「重答」沿用上次冻结的输入、场景和模型，并产生一次新的请求。「新任务」取消当前任务并清空输入和回答。暂停、锁屏和退出会清掉敏感显示。自动写回需要单独开启，而且只写完整回答；请求期间剪贴板变了就跳过。

DeepSeek 官方端点可以选择「沿用模型默认」「直接回答（关闭深度思考）」或「深度思考」。思考过程只显示活动状态，不展示、不保留推理正文。官方端点因 token 耗尽失败时，浮窗会提供一次「直接回答」重试：仅这一次关闭思考，并把生成预算提高到至少 16384，不改已保存的默认值。

在程序设置的「外观」页调整宽度、高度、背景不透明度（25%–100%）、回答字号（11–36）和配色，修改即时预览并自动保存。透明度同时作用于 材料卡片、代码块及主按钮底色；文字与图标保持实色，字号只影响回答。浮窗保留标题拖动和右下角缩放；「舒适阅读」放大并专注回答，「恢复默认」回到 600×740、18 号字和不透明背景。停止按钮仅在处理期间显示，复制和重答在有可用结果时显示；失败后的重试按当前状态提供。设置中的保护详情在「通用 → 诊断与数据保护」查看。

## 分支与版本

发布新版本时，先更新应用项目中的 `Version`、Windows 清单、界面版本及本文件，并在 `CHANGELOG.md` 添加版本记录。提交后创建并推送对应标签（例如 `git tag -a v1.0.1 -m "Release v1.0.1"`、`git push origin v1.0.1`）。`Publish release` 工作流会从标签构建，核对版本，执行核心与 Windows 集成测试，生成自带运行时的 x64 ZIP 和 SHA-256 校验文件，再发布 GitHub Release。带后缀的标签（如 `v1.1.0-rc.1`）发布为预发布版本。也可在 Actions 中手动运行该工作流并填写已有标签；已公开且附件完整的 Release 不会被覆盖。

v1.1.0 包含轻量连续对话。旧版 agent 的结构化任务记忆和工具调用实现在 `codex/ai-coding-agent` 分支。升级时会保留自定义场景提示词；若想切换到新版默认值，可在场景设置中恢复预设后保存。

应用图标、主题与首条回答配色修复、模型连接设置、快捷键和截图发送均保留。工作区诊断写入 `%LOCALAPPDATA%\Superb\diagnostics\workspace.jsonl`，仅包含操作、随机标识、材料数量与安全错误码；每个文件约 2 MiB，最多保留 4 个，不记录正文、截图或密钥。旧 agent 分析配置在迁移前完整备份，再移除不再使用的分析字段。

## 已知边界

当前版本的实际范围如下。

- 协议只有 Chat Completions。不支持 agent 或工具调用；没有 Responses API、Anthropic 原生协议、OCR、文件系统执行工具或浏览器自动化。
- 采集用的是 GDI `BitBlt` 和窗口 `PrintWindow`，不是 Windows Graphics Capture。黑帧和变化的几何范围会被拒绝，也不会退回整桌面。部分 GPU 窗口可能采不到。`PrintWindow` 超过 5 秒后不再使用其结果，底层调用本身停不掉。
- `WDA_EXCLUDEFROMCAPTURE` 设置成功，只说明这个属性能被读回来。它不能证明每一种采集链路都看不到浮窗。外部改掉保护属性之后，到下一次检测之间仍有窗口。
- 程序不隐藏进程，不注入其他进程，也不保证对抗高权限观察者。
- 阅读器不解析 HTML / XAML，不加载远程资源，不跳转链接，不执行命令。

桌面交互里哪些操作会使原窗口失焦，见 [焦点交互排查](docs/focus-interactions.md)。
