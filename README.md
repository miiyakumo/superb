# Superb

当前版本：**0.4.0**。

Windows 11 x64 上的桌面客户端。它从剪贴板或屏幕采集内容，发给你配置的 Chat Completions 接口，在置顶浮窗里流式阅读回答，并可选写回剪贴板。

## 开始使用

在仓库根目录运行：

```powershell
dotnet run --project src/Superb.Desktop
```

生成自带运行时的 Windows x64 目录：

```powershell
dotnet publish src/Superb.Desktop -c Release -r win-x64 --self-contained true -o artifacts/win-x64
```

运行该目录中的 `Superb.exe`，并保留同目录依赖。

### 连接模型

1. 打开「模型」，按接入方式选择模板并点击「新建模型配置」，也可直接填写空白表单。支持 OpenAI 官方、DeepSeek 官方、第三方兼容网关和本机服务，通信协议统一为 OpenAI Chat Completions；其他原生协议需通过兼容网关接入。
2. 填写配置名称、模型 ID、服务地址和服务要求的 API 密钥。URL 可填写域名、以 `/v1` 结尾的 Base URL 或完整 Chat Completions POST 地址；前两种会自动补全路径。自定义路径按完整接口地址使用。本机模板填入 `127.0.0.1:11434/v1/chat/completions`，请按实际服务修改地址和端口；无认证的本机服务可留空密钥。
3. 「测试当前配置」使用当前表单中的模型、地址、参数和未保存密钥，发送固定文本 `Reply with OK.`。新配置不用先保存；测试可能计费，不读取工作区输入或截图，不展示或保存测试回答，也不自动保存配置。成功后点击「保存模型配置」。首次连接自动成为默认；已有默认连接时，保存其他连接不会切换默认项，需在连接列表选中后点击「设为默认」。编辑已有连接时，密钥留空会保留已有凭据。
4. 新建配置默认 200000 生成 tokens、1000000 响应字符、300 秒超时；请按模型服务的实际上限调整。图像能力在高级选项中设置。已保存的后端限额保持不变。DeepSeek 官方端点的本地 tokens 上限为 393216，其他端点为 200000；服务可能要求更低的值。配置或凭据保存失败时保留旧配置。
5. 已有可用后端时，下次启动直接进入浮窗。设置窗口的 × 和页签右侧「返回工作区」只隐藏设置，保留浮窗及当前任务；旁边按状态显示「暂停」或「恢复」。设置顶部仅在配置、快捷键、会话或任务异常时显示状态卡片，普通进度在工作区查看。通过浮窗「设置」可重新打开。结束整个程序需点击「退出 Superb」或使用退出快捷键。

模型连接统一保存端点、密钥、模型和生成参数。场景保留名称、系统提示词和可选的模型连接；未指定时使用当前默认连接。文字与图片使用同一选择规则，包含图片而当前连接不支持图像时，会提示更换连接。需要另一组模型或生成参数时，新建模型配置并让场景选择它。

场景快捷键保留；普通场景切换提示词，AI Coding 协作进入独立的持续任务流程。输入和截图都来自当前工作区队列，准备好后手动发送。用户消息直接附加输入，不再配置 `{input}` 模板或场景截图来源。代理、本机 HTTP、图像能力、温度及其发送开关、token 参数名称和流式兼容选项集中在折叠的「高级选项」里。URL、密钥、tokens 和超时直接展示，详细说明放在悬停提示中；思考模式开关仅在 DeepSeek 官方接口下展示；输入字节数与响应字符数限额保留在内部，编辑连接时原样保留已有值。

旧设置升级到 schema 6 前，会在设置文件旁保存 `.upgrade-*.bak` 原文备份。旧场景的模型与生成参数覆盖迁成独立模型配置并绑定该场景；自定义用户模板中的任务说明移入系统提示词。原有连接、凭据引用、技术限额和场景快捷键保留，固定文字／图片路由不再参与选择。 原先受总开关抑制的独占键迁成逐项停用，原本有效的绑定保持启用；迁移后只按每行的状态与模式注册。

连接失败时的区分和代理写法见 [后端连接排查](docs/backend-connectivity.md)。

## 悬浮工作区

浮窗固定为只读工作区，不提供手输输入框或编辑模式。问题和补充要求从剪贴板加入材料队列，也可使用截图。空白、边框和答案文字上的点击、拖动、滚轮交给下层应用；按钮、场景选择、滚动条、标题拖动区和缩放角仍可操作。使用滚动条或翻页快捷键阅读，点击复制按钮获取回答。显示、拖动和缩放不会主动激活浮窗；右下角缩放保持普通箭头。「全穿透」让按钮等区域也穿透，默认 Ctrl+Alt+E 切换全穿透／恢复操作。穿透、设置、暂停、退出快捷键未注册成功时，不允许进入全穿透。旧编辑快捷键迁移为穿透切换，保留自定义按键及启用状态。

「读剪贴板」「两点截图」「截当前屏」只入队，不会自己把剪贴板发出去。两点截图在同一显示器上点两个对角，顺序不限；右键、Esc 或 60 秒超时取消，已有队列保留。「截当前屏」取鼠标所在显示器，采集时隐藏 Superb。队列最多 10 项，其中最多 5 张图片。正文与 PNG 字节合计不超过 16 MiB。每张图片不超过 3200 万像素，全部图片加在一起也不超过这个数。超出时提示，不删除已有项。

点击「发送」或使用发送快捷键发送队列。发送后「材料队列」收起，给回答留出空间；手动展开后，后续流式更新不会再把它折叠。普通问答和算法场景回答出来之后再收集输入，会开始下一题，并换掉旧队列；AI Coding 保留任务记忆，将新材料用于后续分析。

频繁整屏提问可以点击「发送」旁边的「截屏并发送」，或按默认独占单键 **F4**：截取鼠标所在显示器，使用触发时的场景和模型，**只发送本次截图，单独开始一题**，不带上已有队列文字。截图成功并通过校验后才替换旧队列、问题和回答；截图失败、输入超限或模型不支持图片时保留原内容。取消会阻止迟到截图发送；暂停仍按原规则清空敏感内容。生成期间不会插入新请求，请先停止；「重答」重发已冻结的输入，不重新截图。原有 Ctrl+Alt+D 仍只截图入队。所有快捷键逐行启用，右键按键输入框或按 Shift+F10 配置该行动作的独占模式，不再设置总开关；F4 与其他动作使用同一规则。完整消费无修饰键的按下、长按重复和释放，长按只触发一次。Alt+F4 等带修饰键的组合不由此动作接管。旧版未自定义的 Ctrl+Alt+X 升级为 F4，禁用状态和其他自定义绑定保留；若与已有绑定冲突，保留旧绑定并停用新键。系统注册失败会标记未生效，不降级成会透传的普通按键。浏览器事件是否完全被拦截应以实际平台测试为准，不承诺对所有监听机制不可检测。

「停止生成」留下已生成的部分和当前队列，标成未完成，可以手动复制，不自动写回。「重答」沿用上次冻结的输入、场景和模型，并产生一次新的请求。「新任务」取消当前任务并清空输入和回答。暂停、锁屏和退出会清掉敏感显示。自动写回需要单独开启，而且只写完整回答；请求期间剪贴板变了就跳过。

DeepSeek 官方端点可以选择「沿用模型默认」「直接回答（关闭深度思考）」或「深度思考」。思考过程只显示活动状态，不展示、不保留推理正文。官方端点因 token 耗尽失败时，浮窗会提供一次「直接回答」重试：仅这一次关闭思考，并把生成预算提高到至少 16384，不改已保存的默认值。

在程序设置的「外观」页调整宽度、高度、背景不透明度（25%–100%）、回答字号（11–36）和配色，修改即时预览并自动保存。透明度同时作用于 Coding 分析面板、材料卡片、代码块及主按钮底色；文字与图标保持实色，字号只影响回答。浮窗保留标题拖动和右下角缩放；「舒适阅读」放大并专注回答，「恢复默认」回到 600×740、18 号字和不透明背景。停止按钮仅在处理期间显示，复制和重答在有可用结果时显示；失败后的重试按当前状态提供。设置中的保护详情在「通用 → 诊断与数据保护」查看。

## AI Coding 三方协作

选择「AI Coding 协作」，把题目、当前代码、测试反馈分别复制后点击「读剪贴板」，收集完点击「分析任务」。单份反馈可以用「读取剪贴板并分析」。后端模型维护任务记忆、判断进展和深入诊断；平台 AI 在 Web IDE 执行指令；用户负责转发。Superb 不读取牛客文件树，也不连接或自动操作其 IDE。

生成后，浮窗展示下一步方向、发送前的 `@` 文件操作、平台提示词和需要带回的证据。「复制执行指令」只复制可直接转发的指令正文。平台修改后，把新代码、回复或实际测试结果带回继续分析；不用手工维护分类、轮次或摘要。后端可以直接给出算法、核心代码或完整函数。

任务记忆保留原始观察、带来源的结论以及指令和反馈记录。采集时间不代表文件版本；复制不代表执行；平台声称完成不等于验证通过。两次有独立执行证据的同策略失败，或出现回退，会提示主 agent 重新检查前提与技术策略。缺少关键代码时，指令会要求取得具体片段，不能凭空修改未知文件。

在「程序设置 → 场景」中选择「AI Coding 协作」，可配置调用次数和总时限，保存后对新分析生效；默认不限调用次数、总时限 300 秒，手动调用上限允许 1–10000。模型单次请求默认超时 300 秒，总时限仍独立生效。正在执行与重试沿用冻结配置。

模型只获得两个原生函数：`retrieve_material` 按关键词分页或批量来源范围取回会话原文／图片；`submit_result` 提交完整执行指令，可附本轮需要保存的事实和反馈评估。材料够用可一次调用完成。任务状态自动提供，主 agent 直接分析和自检，旧的记忆管理、进展评估、专家诊断和方案审核工具均已删除，没有旧协议或旧工具回退。

工具调用保留实际调用 ID、参数和 assistant 消息，返回通过匹配的 tool 消息继续；同一任务、同一后端的成功轮次会延续原对话。重复材料可从冻结快照缓存复用；连续三次没有新材料时提示收敛，连续六次没有新材料时暂停分析并保留检查点，可点击「重试任务分析」继续。新证据会清除无进展计数，不再累计第三次相同动作就终止。

浮窗的运行状态区独立于可折叠的输入区，持续显示阶段、累计耗时、模型调用次数和当前请求等待时间，并保留最近的操作摘要。失败会明确显示原因、错误码和重试入口；如果保留了上一轮指令，会明确标注，避免误认为新结果。

后台诊断默认写入 `%LOCALAPPDATA%\Superb\diagnostics\coding.jsonl`，逐行 JSON 包含运行编号、事件序号、UTC 时间、阶段、耗时、调用计数、工具名称枚举和错误码。不包含模型/输入正文、截图、工具参数、提示词、密钥或接口地址。最多 4 个轮转文件，每个约 2 MiB；写入失败不打断分析。程序设置的「通用 → 诊断与数据保护」显示目录。日志从新版启动后的分析开始记录，不能补录旧版已经结束的运行。每次请求还记录连接、DNS/TCP/TLS（可观测时）、上传、响应头和响应体首字节耗时、接收字节数、最后收包间隔及 HTTP 状态。超时条明确显示中止阶段。服务端排队／处理耗时仅从 Server-Timing 白名单数值提取，请求 ID 只保留 SHA-256 指纹；没有服务端指标时不能区分排队与计算。单次请求默认 300 秒，整轮分析总时限仍独立生效。

分析期间可继续读取剪贴板，新材料留在待分析队列，不改变正在执行的输入。失败、停止和无进展暂停保留内存检查点；重试从最后完整工具返回后继续，沿用冻结材料、模型和限额，不重做已完成的检索，也不纳入待分析队列。每次显式重试重新计算本次调用／时间／输出预算。失败后也可在程序设置中调整并保存参数，再点「分析任务」，使用新参数处理保留的材料。新任务清空当前 Coding 任务；应用紧急暂停、锁屏和退出清空所有任务材料，恢复不会找回它们。记忆只存在本次应用会话的内存中，不保存代码或对话到磁盘。

在 Coding 场景中，「截屏并分析」将截图和待分析材料加入当前任务，不开始另一个任务。普通场景的 F4 截屏单独提问行为保持不变。自动复制只写入完整且已通过本地提交校验的指令，剪贴板在分析期间发生变化时跳过。

任务原始材料最多 32 MiB / 1000 份，结构化记忆最多 512 条结论 / 256 条指令；达到限制会明确失败，不能静默丢弃材料。模型能力仍决定诊断质量；程序校验来源、流程和执行证据结构，不能证明模型技术结论一定正确。

## 已知边界

当前版本的实际范围如下。

- 协议只有 Chat Completions。AI Coding 只使用原生工具调用，工具仅操作本地任务记忆与证据；没有 Responses API、Anthropic 原生协议、OCR、文件系统执行工具或浏览器自动化。
- 采集用的是 GDI `BitBlt` 和窗口 `PrintWindow`，不是 Windows Graphics Capture。黑帧和变化的几何范围会被拒绝，也不会退回整桌面。部分 GPU 窗口可能采不到。`PrintWindow` 超过 5 秒后不再使用其结果，底层调用本身停不掉。
- `WDA_EXCLUDEFROMCAPTURE` 设置成功，只说明这个属性能被读回来。它不能证明每一种采集链路都看不到浮窗。外部改掉保护属性之后，到下一次检测之间仍有窗口。
- 程序不隐藏进程，不注入其他进程，也不保证对抗高权限观察者。
- 阅读器不解析 HTML / XAML，不加载远程资源，不跳转链接，不执行命令。

桌面交互里哪些操作会使原窗口失焦，见 [焦点交互排查](docs/focus-interactions.md)。
