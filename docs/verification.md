## 通过的核心用例

1. HTTPS 与显式 IP 回环明文授权。
2. 拒绝 URL 认证、查询参数密钥及未知适配器。
3. 拒绝空输入、超限输入、不支持的图像与无效尺寸。
4. 固定路由不受正文影响，缺失接收方则失败。
5. 图像快照与源字节数组独立。
6. 强制预处理失败阻止发送；可选失败必须有跳过规则。
7. 有序文本处理、模板拼装及直接转发。
8. 同步来源过滤、序列去重及内容去重。
9. 会话授权分别约束到期时间、输入类型、后端与自动发送。
10. SSE 分片 UTF-8、CRLF、心跳与完整结束解析。
11. 拒绝断流、提前 DONE、缺少事件结束分隔符。
12. 拒绝工具调用、长度截断及远端错误正文泄漏。
13. 取消后，忽略不配合取消的传输产生的迟到输出。
14. 旧请求不能覆盖新请求结果。
15. 中断流不能标为成功。
16. 暂停与未授权自动任务不能到达传输层。
17. 策略检查先于传输，失败仅暴露状态码。
18. 可选超限步骤回退到上一个有效产物。
19. 响应限额停止消费，不生成成功事件。
20. 手动尝试创建不同的尝试标识。
21. 锁定后恢复不复活旧请求。
22. 超时取消遵守取消令牌的传输，且不标成功。
23. 实际 HTTP 请求仅携带处理后的内容，未附带原始快照；认证仅在传输时注入。
24. 实际 HTTP 302 被阻止，429 不回显响应正文。
25. 实际 HTTP 完整 SSE 成功接收。
