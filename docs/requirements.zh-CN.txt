文档状态： 待评审  |  日期： 2026-10-16  |  平台： Windows 桌面端
开发一款面向 Windows 的高保密 Agent 转发客户端，通过截屏与剪贴板建立独立于网页交互层的输入通道；按照用户配置对输入进行可选的本地预处理与模型路由，将请求提交至指定的大模型后端，并以流式方式将响应呈现在支持屏幕采集排除的桌面悬浮界面中，同时提供可配置的剪贴板输出同步。
产品应以低可观测交互、最小化数据暴露和全流程用户控制为主要目标，在正常使用过程中尽量减少焦点切换、页面交互、可见界面提示、重复复制粘贴和本地敏感数据留存。
目标平台已确定为 Windows 桌面端；建议首发基线为 Windows 11 x64，具体系统构建号、浏览器及采集软件版本由兼容性矩阵冻结。用户操作其有权使用的设备与内容；本稿不固定编程语言、GUI 框架或模型供应商。
“低可观测”定义为减少本应用产生的额外可观察信号，不等同于进程不可发现。保护范围为已验证的系统采集链路和应用主动产生的数据副本；不承诺对抗已控制本机的高权限程序、物理摄像、第三方已读取的剪贴板副本或已获授权接收内容的后端。网页可见性与剪贴板权限仍受浏览器自身机制约束。[R1][R5][R6]
本文是待评审需求稿，不表示功能已经实现或通过认证。“必须”表示验收要求；P0 为建议首版范围，P1 为增强范围。平台基线、优先级及性能数值均可在评审后调整。
预先配置采集目标、处理模板及后端 → 用户触发或已授权的同步事件 → 获取输入快照 → 本地预处理 → 外发策略校验 → 后端请求 → 接收响应 → 受保护展示 → 按配置写回剪贴板。
采集、发送、显示、复制必须为独立控制动作。配置允许时可组合为一次快捷操作，但会话级自动化授权必须明确输入范围、接收后端和有效期限。
IN-01 · P0　支持指定窗口、指定显示器和预设矩形区域的单次截屏。首次选择和授权可以进入交互界面；已配置目标的日常采集应避免重新切换焦点。
IN-02 · P0　截屏范围必须与用户配置一致；不得因目标失效、越界、黑帧或权限不足，静默扩大为整个桌面。图像应直接进入内存处理，不经系统剪贴板或默认临时文件中转。
IN-03 · P0　支持按次读取剪贴板中的 Unicode 文本和静态位图。空内容、未知格式、大小超限、暂时被占用时必须给出明确状态，不发送空请求。
IN-04 · P0　提供会话级剪贴板同步开关，对连续变更去抖与去重；必须过滤本应用的输出写回，避免响应被再次当作输入。一次变更是否触发外发由独立策略决定。
IN-05 · P0　每次采集生成独立快照并关联请求标识；后续剪贴板变化不得改变已构建的请求。多显示器、DPI 缩放和目标尺寸变化必须正确映射，无法确认范围时暂停采集。
IN-06 · P0　提供可配置快捷键，至少覆盖截屏并处理、读取剪贴板并处理、显示／收起、复制响应、取消和暂停同步；快捷键冲突必须可诊断。
IN-07 · P1　支持在显式会话授权下进行定时或内容变化驱动的重复采集，并设置目标范围、采样间隔、速率上限和自动停止条件。
Windows.Graphics.Capture 提供窗口／显示器帧采集能力，其标准流程包含系统选择界面与采集提示边框。首次授权及系统强制提示不纳入“无可见界面”的承诺。[R3]
PR-01 · P0　支持按顺序启用或跳过处理步骤，包括图像裁剪、实色遮盖、尺寸调整、文本格式整理及提示词模板拼装；允许不修改正文的直接转发流程。
PR-02 · P0　敏感字段遮盖、内容裁剪和允许外发范围检查必须在离开本机前完成。必须发送处理后的产物，不得附带被遮盖的原图、原文、隐藏附件或不必要元数据。
PR-03 · P0　处理步骤必须区分强制与可选。强制步骤失败时阻止发送；可选步骤仅可按照事先配置的规则跳过，并记录不含正文的状态。每个请求冻结所用模板和处理版本。
PR-04 · P1　支持本地 OCR、敏感信息规则识别和多输入合并。远端 OCR 或额外模型预处理必须作为独立外发步骤声明接收方，不得伪装成本地处理。
BE-01 · P0　支持多个后端配置，包含端点、协议适配器、模型、认证凭据引用、文本／图像能力、超时及生成参数。凭据与普通配置分离保存。
BE-02 · P0　支持手动选择及固定规则路由；请求发送前必须冻结后端、模型、处理结果和参数。输入文本、截图内指令或模型输出不得修改外发策略及认证信息。
BE-03 · P0　在发送前校验输入格式、大小和后端能力。对不支持图像的后端，应阻止请求或使用已授权的文本提取流程，不得静默丢弃图片或更换供应商。
BE-04 · P0　支持流式接收与完整响应接收，正确处理分片文本、错误和结束信号；区分连接中、等待响应、生成中、已完成、失败和取消，不得把中断流标记为成功。
BE-05 · P0　请求、流事件、界面更新和剪贴板导出必须关联请求标识与会话代次；旧任务的迟到数据不得覆盖新任务。取消后停止本地消费和输出，并尽力终止传输。
BE-06 · P0　超时、限流或连接中断不得触发跨信任边界的自动后端切换。提交状态不明或已经收到响应时，自动重发必须受显式重试策略约束；手动重试创建新的尝试标识。
BE-07 · P1　支持可控会话上下文、请求队列和经过授权的故障切换。默认请求上下文独立；复用历史、并行外发或路由到备用后端必须由用户配置。
首版 Agent 定义为受控的输入编排、处理、模型调用及响应分发，不默认包含自主执行 Shell、操作浏览器或读取任意文件的能力。后续工具调用应另行定义工具许可、参数约束、执行确认和预算。
UI-01 · P0　提供桌面置顶悬浮阅读面板，支持流式文本、换行、滚动、代码块及基本排版；位置、大小、字号和显示／收起状态可配置。
UI-02 · P0　在发布兼容性矩阵所列的采集链路中，悬浮窗及其敏感内容必须从采集结果中排除。采集排除必须覆盖首次显示、持续流式更新、移动、缩放、显隐切换和窗口重建。
UI-03 · P0　敏感内容首次渲染前必须完成窗口保护设置及可检查条件的校验。设置失败、保护窗口重建未完成或已检测到保护异常时，停止显示敏感内容，以无正文的状态提示替代，不自动降级。
UI-04 · P0　回答正文、输入预览、敏感错误详情及派生内容只能进入受保护显示路径；普通通知、窗口标题、任务栏预览、独立提示窗、系统菜单和调试窗口不得携带敏感正文。
UI-05 · P0　保护状态应分别标识“属性已设置”“当前配置已测试”“未验证／不支持”。不得仅凭 API 返回成功宣称所有录屏或共享工具均不可采集。
UI-06 · P0　阅读面板默认不激活；显示、更新、翻页、收起以及复制操作不得主动改变前台应用。阅读窗默认不进入任务栏和 Alt+Tab 列表；设置窗口由用户主动打开。
UI-07 · P0　默认关闭通知弹窗、提示音、任务栏闪烁和回答完成后的自动窗口跳转。状态在阅读面板内部呈现；用户必须始终可以通过明确入口查看当前模式、暂停或退出。
UI-08 · P0　提供紧急暂停动作：立即遮蔽本应用的敏感显示，停止新的采集与自动外发，终止本地响应输出；是否清除会话内存及本应用写入的剪贴板由明确策略控制。
UI-09 · P1　支持独立的指针穿透阅读模式与显式交互模式。切换模式不得造成未受保护的替代窗口；快捷键路径应始终可用于收起和退出。
WDA_EXCLUDEFROMCAPTURE 自 Windows 10 2004 起受支持，作用于本进程顶层窗口，并依赖 DWM。微软将其限定为对一组公共采集机制的保护，而非对任意采集方式的安全保证。[R1]
WS_EX_NOACTIVATE、WS_EX_TOOLWINDOW 和 WS_EX_TOPMOST 可作为交互原型的基础。鼠标悬停激活设置还可能改变行为，验收须单独覆盖该系统选项，而非只检查窗口样式。[R2][R8]
CB-01 · P0　支持手动复制完整回答，并提供独立的“生成完成后自动写回”开关。自动写回默认关闭；启用后只写入已完成的对应响应，不逐片覆盖系统剪贴板。
CB-02 · P0　输出写回必须带有本应用可识别的来源和代次，并与输入监听去重逻辑协作。连续自动输入与输出时不得产生递归调用、重复扣费或自激式请求循环。
CB-03 · P0　请求期间剪贴板若被用户或其他应用更新，默认跳过自动写回并在受保护面板提示。检查与写入必须处理并发竞争；主动复制可以按用户当次指令覆盖。
CB-04 · P0　本应用写回时必须附加阻止进入 Windows 剪贴板历史及云同步的格式标记。该功能不作为阻止其他应用读取当前剪贴板的访问控制。[R4][R6]
CB-05 · P1　支持剪贴板到期清除；只在能够确认当前内容仍对应本应用写入代次时执行，避免删除用户之后复制的内容。清除不得被描述为撤回第三方已取得的数据。
SEC-01 · P0　默认不持久化截图、输入正文、模型回答和会话历史。日志、崩溃报告、导出配置、命令行参数及普通错误信息不得包含这些内容或密钥；遥测和自动崩溃上传默认关闭。
SEC-02 · P0　认证凭据使用当前用户范围的系统安全存储或等效机制保存，普通配置只保存引用。显示凭据应掩码，配置导出默认不含凭据。
SEC-03 · P0　远端通信必须使用加密传输并验证服务端证书；拒绝将带凭据的请求静默重定向至未授权主机。仅明确配置的本机回环后端可使用本地明文连接。
SEC-04 · P0　所有网络外发应经过统一策略入口，目标限于获授权的模型端点及明确配置的依赖。固定预处理步骤和响应渲染默认不得自行联网。
SEC-05 · P0　将输入和模型响应视为不可信内容；渲染时禁止执行脚本、自动加载远程资源或触发命令。正文不得改变模型路由、密钥访问、同步开关或工具权限。
SEC-06 · P0　暂停、退出、锁屏或用户切换时停止自动输入与输出；锁屏后清除敏感显示，解锁不自动恢复同步。应缩短内存副本生命周期，但不承诺对系统分页、休眠及第三方转储的绝对清除。
“剪贴板同步”在本文中指本机系统剪贴板的输入／输出，不指跨设备同步。远端模型及代理可能接触已发送内容；后端选择和服务端留存政策是独立的信任条件。
请求主流程：Idle → Capturing → Processing → PolicyCheck → Sending → Streaming → Completed。非流式后端可从 Sending 直接进入 Completed；各执行阶段均可转入 Failed 或 Cancelled。需用户确认时进入 AwaitingApproval，再重新进行发送前策略检查。
请求状态与全局运行状态分离。全局状态至少包括 Ready、Paused、Locked 和 ProtectionUnavailable；暂停、锁屏或保护不可用时阻止新的自动任务与敏感显示。已经发送的数据不因本地取消而被保证撤回。
以上数值为待基准测试确认的设计目标，不是已测结果。性能测试须固定硬件、系统构建号、DPI、图像尺寸和负载；模型推理及公网延迟单独报告，不计入本地性能承诺。
每项验收记录必须包含客户端构建版本、Windows 构建号、显示配置、相关浏览器／采集软件版本、操作步骤、预期结果与实测证据。截图保护仅对实际通过的组合宣称兼容。
至少区分显示器采集、窗口采集、浏览器屏幕共享及选定录屏程序；覆盖单屏／双屏、100%／150%／200% DPI、窗口重建和系统鼠标悬停激活。远程桌面、HDR、独占全屏及其他未测组合标为未验证，不继承普通桌面的测试结论。
发布门槛：P0 流程闭环；敏感内容默认不落盘；同步无回环；取消无迟到输出；声明支持的采集组合通过逐帧检查。API 调用成功不能替代这些验收证据。
P0：预设目标截屏、文本／图像剪贴板读取、显式会话同步、基础预处理、多后端配置与固定路由、流式响应、受保护阅读面板、低干扰快捷键、手动及可选自动写回、敏感数据控制和上述验收机制。
P1：连续采集、本地 OCR、规则化敏感信息识别、多输入合并、可控会话上下文、请求队列、授权备用后端、指针穿透及剪贴板到期清除。
首版不包含浏览器自动填表、任意文件搜集、通用自主工具执行或跨设备剪贴板同步。实现采用系统支持的用户态机制；不要求浏览器注入、进程伪装、内核隐藏或关闭系统强制安全提示。
显示保护可评估 SetWindowDisplayAffinity 与 WDA_EXCLUDEFROMCAPTURE；窗口交互可评估 Win32 扩展样式；输入采集可评估 Windows.Graphics.Capture。最终选型须通过第 7 节测试。[R1][R2][R3]
剪贴板历史与云同步控制可使用 ExcludeClipboardContentFromMonitorProcessing，或分别以零值设置 CanIncludeInClipboardHistory、CanUploadToCloudClipboard。[R4]
持久化密钥可评估用户范围的 DPAPI。其解密通常与相同登录凭据关联，不作为同用户会话中所有进程之间的强隔离保证。[R7]
首发 Windows 构建号与架构；后端协议与供应商清单；支持的截图／共享程序及版本；最大输入尺寸、请求超时与重试规则；同步会话期限；默认快捷键；性能测试硬件。上述参数应在实现前建立配置基线，不改变原始功能目标。
