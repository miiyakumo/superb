## 采集排除矩阵

每种链路分别覆盖单屏与双屏、100% / 150% / 200% DPI、混合 DPI、窗口首次显示、逐片生成、拖动、缩放、隐藏/显示、窗口销毁/重建。逐帧检查合成的敏感标记是否出现。只要出现一帧就失败。重新创建保护窗口前不得把正文送入该窗口。

| 链路 | 采集目标 | 指定软件与版本 | 结论 |
| --- | --- | --- | --- |
| 系统显示器采集 | 含阅读面板的显示器 | 待冻结 | 未验证 |
| 系统窗口采集 | 原应用 / 阅读面板 | 待冻结 | 未验证 |
| 浏览器共享屏幕 | 整个显示器 | 浏览器及会议页面版本待冻结 | 未验证 |
| 浏览器共享窗口 | 原应用 / 阅读面板 | 浏览器及会议页面版本待冻结 | 未验证 |
| 指定录屏工具 | 显示器 / 窗口来源 | 程序与捕获方式待冻结 | 未验证 |
| RDP / HDR / 独占全屏 | 各模式独立 | 待单独评审 | 未验证，不继承其他组合 |

## 必测场景

| 编号 | 步骤 | 预期 |
| --- | --- | --- |
| A01 | 启动客户端，未配置后端；检查网络与临时文件 | 无模型外发，无内容文件；同步及自动写回关闭 |
| A02 | 配置一个窗口，移动/缩放/关闭并复用 HWND | 停止采集，要求重新配置，不扩成桌面 |
| A03 | 在负坐标副屏配置矩形，切换 DPI/分辨率/布局 | 范围一致或明确停止，不越界、不扩大 |
| A04 | 最小化窗口、无权限窗口、黑帧、GPU 窗口 | 明确失败，无自动回退或空请求 |
| A05 | 剪贴板空、未知格式、文本与位图、大小超限、占用 | 明确状态；有效内容冻结为单次独立快照 |
| A06 | 请求前采集 A，紧接着外部复制 B | 模型收到 A；自动写回不覆盖 B |
| A07 | 同步输入且开启自动输出，快速复制相同/不同内容 | 去抖、去重、过滤输出；无自激请求循环 |
| A08 | 自动准备过程中停止 Live Clipboard/到期/改后端/改规则 | 尚未提交的自动任务失效；已经提交的请求不被伪装成“已撤回”，仍可用取消或紧急暂停停止本地消费/显示 |
| A09 | 遮盖后捕获实际请求体并解码 PNG | 被遮盖像素为实色，不含原图、原文、元数据 |
| A10 | 强制步骤失败；可选步骤分别允许/不允许跳过 | 前者阻止；只有明确允许的可选失败跳过，状态无正文 |
| A11 | 给文本后端提交图像；输入中要求改供应商或泄露密钥 | 拒绝不支持的图像；正文不改变路由/认证 |
| A12 | 后端 302、429、超时、证书错误、断流、缺结束信号 | 无重定向、自动重试或换供应商；不标为成功 |
| A13 | 发送 A、取消、发送 B，再使 A 迟到 | A 不覆盖 B，不复制 A，不出现迟到完成 |
| A14 | 保护设置失败/属性移除/DWM 异常/窗口重建 | 正文遮蔽，自动任务撤销；不降级显示 |
| A15 | 开启“鼠标悬停激活窗口”，操作阅读面板、翻页和复制 | 前台 HWND 不变；任务栏/Alt+Tab 无阅读面板 |
| A16 | 锁屏、快速用户切换、RDP 断开、挂起、恢复 | 显示清空、同步停止，恢复后保持暂停 |
| A17 | 输出写回后查看 Win+V 和跨设备剪贴板 | 合成输出不进入历史/云；当前剪贴板仍可被其他应用读取 |
| A18 | 输出后由另一应用复制，再暂停或退出 | 不删除后来复制的内容 |
| A19 | 检查普通标题、通知、系统菜单、缩略图、错误、导出、文件写入 | 无输入/回答/密钥；导出无凭据引用；无自动内容日志 |
| A20 | 固定环境测量本地采集/处理/首次渲染/取消时间与内存 | 实测记录 P50/P95；模型与公网延迟独立列示 |
| A21 | 热键冲突、默认热键全部被占用 | 可诊断，控制中心仍可暂停和退出 |
| A22 | 阅读界面输入脚本/图片链接/命令/恶意 XAML | 仅显示文本，不执行、不加载、不另行联网 |

## 发布门槛

P0 闭环与所有安全相关测试通过；声明支持的采集组合逐帧验证通过；同步无回环；取消无迟到输出；敏感正文默认不落盘。保留构建、版本及证据，逐项签字。任一不支持或未测组合必须清楚标为未验证。API 返回成功、单元测试通过和 CI 构建通过都不能替代平台实测。
