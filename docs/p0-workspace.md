# P0 悬浮工作区改造

日期：2026-10-21（Asia/Shanghai）。

## 使用行为

- 已连接后端时启动进入置顶工作区，配置窗口仅在首次连接、设置或关键快捷键不可用时保留。连接测试成功后也进入工作区。
- 阅读模式保留不激活行为；直接点击输入框或场景即可进入交互，并在同一次点击放置光标或打开选择器。也可用“编辑”或可配置的 `interact` 快捷键进入。Esc 返回阅读。显示、流式更新、翻页和复制不会主动进入编辑。
- 穿透模式使用 WPF 管理的分层窗口及原生透明命中样式，要求编辑返回键与设置、暂停、退出键均已注册。隐藏再显示回到普通阅读；重新注册导致返回键失效时退出穿透。
- 场景选择与输入来源分离。剪贴板文字、剪贴板图片、两点截图与当前屏幕统一追加到内存队列，展示来源、摘要或缩略图；可以逐项移除、移除最后一项或清空，再添加补充要求。队列最多 10 项、其中 5 张图，累计大小最多 16 MiB、图片累计最多 3200 万像素；超限不丢弃已有项。
- 发送时冻结整个队列、草稿、场景、模型及配置，沿用全局预处理、强制遮罩、固定路由、能力校验和既有 Chat Completions 客户端。每张图片分别执行相同预处理，任意强制步骤失败则阻止整批。没有模型时打开连接页。
- 两点截图采用短时进程内鼠标／键盘钩子，依次点击同屏两个对角，选点的完整点击周期被消费。右键或 Esc 取消、60 秒超时，保留队列；采集前隐藏两个窗口，使用既有 GDI 采集及几何校验，不回退到全屏。当前屏幕按鼠标位置选显示器，均无需预设目标。回答结束后再次成功收集输入开启下一任务；取消截图不会清空旧任务。
- 原有一键场景快捷键保留其绑定来源和一步发送行为；界面按钮仅选择场景。Ctrl+Alt+1 / 2 改为读剪贴板／两点截图入队，Ctrl+Alt+D 截当前屏，Ctrl+Alt+Backspace 移除最后一项，Ctrl+Alt+7 发送整个队列和问题。场景快捷键的截图来源仍使用“更多”中的预设范围。
- 停止生成与清空分离：停止冻结部分回答并使旧传输代次失效；新任务清空输入、输出及待发送内容；紧急暂停、保护失效、锁屏、退出仍清除敏感内容。
- 部分回答只能明确手动复制，不自动写回。重新回答沿用上一请求冻结的内容和接收方，并创建新的尝试。
- 推理模型的思考活动显示为独立状态，不展示或保留推理正文；生成 token 耗尽、内容过滤、中断和空回答分别显示原因。DeepSeek 的直接回答开关为显式选项，旧后端仍沿用原参数；新快速配置使用 65536 tokens、300 秒。因 token 耗尽失败时可在浮窗明确选择单次“直接回答（16K tokens）”恢复，不自动重试、不覆盖保存的设置。默认算法提示词改为识别关键操作、简洁题解与可提交代码，只升级未改动的旧内置提示词，保留自定义内容。
- 浮窗使用本地文本／代码阅读组件，不执行 HTML、XAML、链接或远程资源。流式更新保留已提交段落与文档对象；用户上翻后保留视口，通过“回到最新”恢复跟随。
- 回答区优先占用可用高度；开始连接模型后折叠输入与队列，用户再次展开后不会被后续 token 收起。展开的输入区内部滚动，收集新项目会展开；新任务恢复输入。紧凑按钮和固定 14 号控件不随回答字号一起增大。
- “外观”内提供宽、高、背景不透明度和回答字号滑块；不透明度只改变底色，不使用 Window.Opacity、不改变保护或穿透样式。默认不透明；右下角独立 Thumb 提供明显的缩放入口，明确拖动会请求交互模式以支持鼠标捕获。“舒适阅读”和“恢复默认”均保留草稿、队列和回答。尺寸按当前屏幕工作区约束，最小 360×480；停止调整 500ms 后保存外观，后台测试宿主不写用户配置。
- 浮窗按钮使用统一的第二行快捷键提示，来自当前配置与 HotkeyManager 注册结果，随重新注册刷新；未分配的鼠标操作、已停用、独占接管关闭、注册失败均有独立状态。发送可回退到另一已注册发送键或交互模式的 Ctrl+Enter，暂停／恢复和截图取消按当前动作显示。部分回答复制、直接回答恢复与普通全局键的语义差异保留；仅队列最后一项对应最后一项移除键。较长绑定省略时可悬停提示查看全文。

- 配置窗口仅保留“模型、场景、快捷键、更多”四页，移除重复的提问框、队列入口和回答显示；一键场景的手动问题来源直接读取浮窗草稿。模型的端点与密钥、代理及兼容参数折叠显示，场景优先展示名称和系统提示词；模型、场景与快捷键的保存按钮固定在可见页底。快捷键和剪贴板偏好独立构建保存候选配置；打开设置保留上次所选页，不清空浮窗任务。外观只在浮窗调整，原 Panel 配置继续保留。

## 实现位置

- `MainWindow.Workspace.cs`：输入收集、发送、停止、新任务及浮窗动作状态。
- `WorkspaceDraft.cs`：只在内存存在的混合输入队列、容量校验和补充文字冻结。
- `Platform/TwoPointSelector.cs`：短时两点选区及取消，完成后释放原生钩子。
- `ReaderWindow`：悬浮工作区与明确的交互／阅读／穿透模式。
- `ReaderWindow.Appearance.cs`：只调节背景透明度、正文大小、工作区尺寸和阅读空间，发出外观保存事件。
- `AnswerView.cs`：浮窗的增量文本阅读器。
- `Coordinator.Stop`：保留不完整输出，同时撤销旧传输的有效代次。
- `Protection`：保留显示保护检查，为明确的窗口交互模式校验对应原生样式。

设置仍为 schema 2。新增编辑快捷键通过原迁移入口补入；已有动作或场景占用 Ctrl+Alt+E 时保留旧绑定，停用新增绑定，不覆盖用户配置。未读取真实模型密钥进行验证。

## 验证

执行命令与结果见 `verification.md` 末尾本次记录。普通 Windows 测试使用隔离的生产工作区和合成后端，不加载用户设置、不注册全局快捷键、不读取／覆盖剪贴板、不保存配置。交互式测试验证原生样式、显示时前台保持、鼠标命中穿透、显隐恢复和显示保护属性；编辑激活与前台恢复还受 Windows 前台授权及实际输入来源影响，不能用后台测试进程的 Activate 返回值代替完整桌面交互验收。

WPF 分层窗口是本次窗口行为变更。当前采集链路仍未经过逐帧排除验收，既有采集保护发布限制继续适用。
