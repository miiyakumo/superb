观察事件，不屏蔽事件。测试浮窗是否改变焦点，以及哪些按键传到了网页。

1 · 准备一次操作

仅使用合成内容。日志包含按键 code、修饰键和时间，不读取输入框正文、剪贴板或其他网页；不联网、不自动保存。按键 code 仍可能反映所按字符。

开始后，在 10 秒内执行所选操作。尽量等待自动停止后再返回此页，减少回到网页产生的额外事件。每个场景建议重复三次。

2 · 观察结果

尚无采样。没有事件只有在操作确实执行、记录器工作正常时才有意义。

3 · 判读边界

window.blur 表示窗口失焦；focusout 只可能是页面内控件切换，不能当作窗口失焦。visibilitychange 与失焦分别统计。isTrusted=true 也可能来自自动化输入，并不证明是真人按键。没有触发本测试页事件，不代表其他网站、扩展或本机程序无法观察操作。

本页不会阻止默认按键、覆盖浏览器焦点 API，或安装全局键盘钩子。导出是手动触发，刷新后内存记录消失。
